Rules

How the colour is spent

  1. One deep field per page: the Canopy closing band. Lagoon only for the three teal moments.
  2. Every page hero sits on Meadow, so the site reads as one place.
  3. Red only on the primary action and the 4 px header stripe; on a deep field the red button carries a white ring.
  4. White text only over forest or teal, never over sage. No gradient text: SharePoint cannot render it.
  5. Numerals light, headings medium, labels in sentence case.
  6. Dots stay the only motif: they gather when a lesson is kept and scatter when it is lost.

Board note. The gradients reach SharePoint as images generated from these tokens, with no IT request. The type sizes need custom.css (tier 2): the theme sets colours, not sizes, so without it SharePoint's own smaller sizes apply.
