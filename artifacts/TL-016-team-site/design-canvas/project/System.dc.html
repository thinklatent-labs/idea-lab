Rules

How the colour is spent

  1. One deep field per page: the deep forest closing band. Teal only for the three teal moments; green for attention.
  2. Every page hero sits on Meadow, so the site reads as one place.
  3. Buttons are black. Red is the one main action of a view, the 4 px header stripe and the placeholder logo tile; on the deep band the red button carries a white ring. Green never fills a button. Status marks use the kit's status colours (a miss is #D04408), never the host red.
  4. White text only on the deep forest band. Glass is flat, with no gradients or grain; the only soft field is under the hero, clear of the text.
  5. Numerals light, headings medium, labels in sentence case.
  6. Dots stay the only motif: they gather when a lesson is kept and scatter when it is lost.

Board note. The backgrounds reach SharePoint as images generated from these tokens, and the theme's black primary makes every native button the kit's black button, with no IT request. The type sizes are typed by hand in the Text web part, which takes 8 to 250 (tier 1); custom.css only makes them automatic and adds the red main action and emerald links (tier 2).
