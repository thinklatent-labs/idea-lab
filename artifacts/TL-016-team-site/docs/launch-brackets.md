# ThinkLatent site — launch brackets to fill (TL-016)

Nov 7, 2026 · @Jithin Pradeep

Every value the v10 site needs that only the Enterprise holds: 171 lines on the fourteen launch pages, plus 19 on ThinkLatent Day, which wait for the AI Summit date. Rebuilt on 16 Nov from design canvas v10 (D-381) and the [page copy doc](https://claude.ai/artifact/SYuzrTCs1uxD9f5b3H9Ru5); the v8 list of 7 Nov is in this doc's history.

## How to fill

- Fill each line in SharePoint as you build its page, and note the value here so the 21 Nov check can be counted. The groups follow the system each value comes from, so each system is opened once.
- A number goes live only with its source system and date; a person is not a source (D-192). A line without both stays off the live page.
- Quotes need the partner's written approval: note where it is kept. Names go up only with the person's agreement.
- The lab cannot fill any of these. Canvas v10 already carries every fact the lab holds: the TLM line, the platform, the portal and TL Index status, the fast-lane latency target and the glossary.
- Fields that authors fill in a template when they write are not listed.

## The 21 Nov check

It passes when at least 86 of the 171 launch lines have a value, a source and a date. Otherwise the launch is cut to six pages: Home, Mandate and Products, Wins, Team, Blog, and At a glance (D-191).
