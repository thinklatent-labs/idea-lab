How an agent gets here

  1. A pattern shows up in several use cases (Quality page clusters, or the agent portfolio).
  2. ThinkLatent builds it as an agent with tools, policy and the models it may run on.
  3. Agent evaluation: task success, tool-call correctness, groundedness, cost per task, human review.
  4. Validators approve it once; it is marked approved for the portal and Relay.
  5. Teams adopt it into a project; feature requests feed its roadmap.
Blueprints as code are retired; an agent is the reusable thing now.
