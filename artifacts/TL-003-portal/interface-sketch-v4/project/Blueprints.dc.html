Session-aware application

Planned

Everything clever about a session happens inside the endpoint, on ThinkLatent's side; there is nothing to build or see. This blueprint shows the application how to use what comes back: open a session, read what was prepared, report what happened.

  • Open and resume a session through Relay; nothing else changes in the call
  • Read the summary, entities and suggested next step the endpoint attaches to a session
  • Send outcomes and feedback so the session improves the next answer

Inner-source rules Fork freely; contributions go through maintainer review; a blueprint nobody forks in two quarters is retired.
