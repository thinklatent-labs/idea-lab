AI guide

draft · not in great shape yet
How Claude Code sessions work with ThinkLatent: what they may read, what they must ask before, how they report, and how people use them.
  • Read: repositories and the bridge database; never production data
  • Ask before: opening a PR, rotating keys, changing a record, anything that costs GPU hours
  • Report: results and requests go to the database with the session and the instruction they answer
  • On push: read the change, run the suite, write the result here
  • People: send from the portal (desktop or phone); approve here; never from a terminal alone for the above
