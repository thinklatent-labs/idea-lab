What the registry stores Engineering view

What the registry stores per row and how to read it through Relay.
Registry API
Written by the pipeline
version, kind, built_from, training_run, checkpoint, dataset_versions, official_run_id, pillar scores with intervals, bars_cleared, owner
Written by the gateway
aliases (prod, canary, candidate, previous), use_case_bindings, endpoint_build, serving settings, cost_per_mtok, last_reconciled
Written by people
lifecycle decisions only (approve, deprecate, retire), each with approver and evidence run id; see the lifecycle record
Evidence expiry
vendor rows carry evidence_expires_at and a scheduled re-run; see Open-weight and vendor
from relay import Registry

r = Registry()

row.status            # "current"
row.owner             # "Priya N."
row.official_run_id   # 1180
row.bars_cleared      # (5, 5)
row.cost_per_mtok     # 0.42
