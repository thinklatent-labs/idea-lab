How cost is counted
Dedicated machines · a fixed monthly share
Each production use case pays its share of the dedicated endpoint it runs on, by the capacity reserved for it, whatever it sends that month. Production runs only on dedicated endpoints.
Shared serving · per token
Sandbox, POC, build, pilot on the shared pool and training traffic pay per token at the published rate, $0.42 per million tokens blended, from the gateway serving log.
Vendor-equivalent · Finance method v1.2
The list price of the frontier API in the use case's quality band times measured tokens. Versioned by Finance; v1.1 used estimated tokens and was restated, see the corrections log.
