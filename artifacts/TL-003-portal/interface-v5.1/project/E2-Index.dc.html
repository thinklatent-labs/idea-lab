In plain language. The Index answers one question for each workflow at the Enterprise: which models are good enough, and what does each one cost to run. "Good enough" is set by the workflow's owner in its record, not by the Index; the scorecard also marks each pillar's own Index bar, set by the pillar council. A model that clears every bar is sufficient; among sufficient models the cheapest is usually the right default. The dots are models; the line joins the ones you cannot beat on both quality and price at once. The ± figures say how sure we are: when two models' intervals overlap, we call them a tie rather than rank one above the other. Every number names the Official run it came from; numbers from build or pilot environments are marked Non-production.
