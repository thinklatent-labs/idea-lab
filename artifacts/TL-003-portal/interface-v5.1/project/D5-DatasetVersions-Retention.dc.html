How items follow the use case

Boundary
Every item carries UC-0291's boundary, Retail Advice · US client data, into every version and into any steward copy. It never leaves for a project outside that boundary.
Retention class
R3 · client interaction records. An item lives only as long as its source record, and at most 7 years from capture.
When a source record goes
Every version holding its items is withdrawn and not servable; a new version is cut without them; every run and Official evidence item that used a withdrawn version is flagged withdrawn data.
Versions stay immutable
A withdrawn version keeps its manifest, its diffs and its place in the lineage, so past runs stay explainable. Nothing can train or evaluate on it.
Copies follow
The UC-0118 steward copy of v4 holds none of the deleted items, so it is unaffected. A copy that held them would be withdrawn the same way.
Next retention date
The earliest capture in advisor-notes is 3 Mar 2021, so no item reaches the 7-year limit before 3 Mar 2028.
