Call it through Relay

Needs a registered use case · production calls use dedicated endpoints only
See your traces
Model name
The alias: tlm4-core:prod follows the current release; the code does not change when the route moves
Tags
use_case, stage, task, prompt_id, end_user on every call · end_user hashed on your side, never sent raw
Outcome and feedback
client.outcome · accepted, edited or discarded · client.feedback · 1 to 5
Request id
reply.request_id · keep it beside your logs; support, replays and disputes start from it
Python
from relay import Client

client = Client(use_case="UC-0291", stage="pilot")         # key is scoped to the use case
reply = client.generate(
    model="tlm4-core:prod",                               # the alias is the model name
    prompt_id="advisor-summary/v3",
    task="summarise-meeting",
    end_user=client.hash_user(advisor_id),                 # hashed here, never raw
    input={"notes": notes},
)
print(reply.text, reply.request_id)

client.outcome(reply.request_id, "accepted")              # accepted | edited | discarded
client.feedback(reply.request_id, score=4)                 # optional reason="..."
