Custom recipe Engineering view

Three sections. Fields changed from Recommended carry a "changed" chip. Save keeps a named, versioned copy for the team; Reset puts every field back to Recommended.
A recipe change is a new run, never an edit. A run's recipe is frozen when it starts and stored with the run. To change a field on a running or finished run, start a new run from a copy; the old run keeps the recipe it was trained with, so its results stay explainable.
