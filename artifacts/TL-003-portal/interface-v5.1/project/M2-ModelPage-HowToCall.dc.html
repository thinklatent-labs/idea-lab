How to call it Engineering view

Through Relay. The snippet carries the telemetry contract: the alias is the model name, five tags ride on every call, and one line each reports the outcome and the feedback.
Model name
The alias: tlm4-core:prod follows the current release; tlm4-core-4.2 pins this version
Required tags
use_case, stage, task, prompt_id and end_user, hashed on your side and never sent raw
Outcome
client.outcome(request_id, "accepted") · accepted, edited or discarded
Feedback
client.feedback(request_id, score) · 1 to 5, with an optional reason
from relay import Client

client = Client(use_case="UC-0291", stage="pilot")         # key is scoped to the use case
reply = client.generate(
    model="tlm4-core:prod",                               # the alias is the model name
    prompt_id="advisor-summary/v3",
    task="summarise-meeting",
    end_user=client.hash_user(advisor_id),                 # hashed here, never raw
    input={"notes": notes},
)
print(reply.text, reply.request_id)

client.outcome(reply.request_id, "accepted")              # accepted | edited | discarded
client.feedback(reply.request_id, score=4)                 # optional reason="..."

Migration guides Engineering view

Moving from a vendor API is two changed lines plus the tags. Moving from Core 4.1 is a model name and a re-evaluation.

From a vendor API

Relay speaks the same chat-completions shape most vendor SDKs use. Change the base URL and the model name; add the five tags.
from openai import OpenAI

client = OpenAI(base_url="https://api.vendor.example/v1", api_key=VENDOR_KEY)
client = OpenAI(base_url="(source link withheld)", api_key=RELAY_KEY)
reply = client.chat.completions.create(
    model="vendor-frontier-a",
    model="tlm4-core:prod",
    messages=messages,
    extra_headers=vi_tags,   # use_case, stage, task, prompt_id, hashed end_user
)
Differences to expect
Context
32k tokens, best under 24k. Longer inputs are refused by the gateway, not truncated; split long documents.
Output format
JSON mode is strict: trailing prose after the object is dropped. Citations are built in; remove your own "cite the source" line.
Tools
One tool call per turn. Parallel tool calls are not supported yet; the request still succeeds with the first call.
Inputs
Text only. Image and audio parts return an error that names the request for a vision model.
Limits
Tokens per minute are set per use case at onboarding, not per account. A 429 names your use case's limit.
Scope
It declines investment advice and anything outside your registered use case, with a short reason in the reply.
Cost and speed
About $0.42 per 1M tokens against the $6.00 contract price of Vendor frontier model A; TTFT p95 410 ms on the dedicated endpoint.
Re-evaluate
Run your item set as a Practice run before you move traffic; production needs an Official run and a validation.

From Core 4.1

Model name
Change tlm4-core-4.1 to tlm4-core-4.2, or bind to tlm4-core:prod to follow current.
Prompt template
System preamble shortened; the "cite the source" instruction is now built in. Templates with their own citation line produce duplicates.
Output format
JSON mode is strict; trailing prose after the object is no longer returned.
Re-evaluation
Required. Start a Practice run on your item set, then request an Official run before changing the prod alias.
