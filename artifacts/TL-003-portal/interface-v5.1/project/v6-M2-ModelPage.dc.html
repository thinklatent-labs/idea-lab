Call it through Relay

Needs a registered use case · production calls use dedicated endpoints only
Try it in the playgroundSee your traces
Model name
tlm4-core:prod follows the current release · tlm4-core-4.2 pins this version
Required tags
use_case, stage, task, prompt_id, end_user · end_user hashed on your side, never sent raw
Outcome
client.outcome(request_id, "accepted") · accepted, edited or discarded
Feedback
client.feedback(request_id, score) · 1 to 5, with an optional reason
Python
from relay import Client

client = Client(use_case="UC-0291", stage="pilot")         # key is scoped to the use case
reply = client.generate(
    model="tlm4-core:prod",                               # the alias is the model name
    prompt_id="advisor-summary/v3",
    task="summarise-meeting",
    end_user=client.hash_user(advisor_id),                 # hashed here, never raw
    input={"notes": notes},
)
print(reply.text, reply.request_id)

client.outcome(reply.request_id, "accepted")              # accepted | edited | discarded
client.feedback(reply.request_id, score=4)                 # optional reason="..."

Differences from a vendor API
Context
32k, best under 24k · longer inputs are refused, not truncated: split them
Output format
Strict JSON drops trailing prose · citing is built in: drop your cite line
Tools
One tool call per turn · no parallel calls yet; the first call still runs
Inputs
Text only · image or audio parts error, naming the vision-model request
Limits
Tokens per minute set per use case at onboarding · a 429 names your limit
Scope
Declines investment advice and out-of-scope asks, with a short reason
Cost and speed
$0.42 per 1M tokens vs $6.00 for Vendor frontier model A · TTFT p95 410 ms
Re-evaluate
Practice run first · production needs an Official run and a validation
