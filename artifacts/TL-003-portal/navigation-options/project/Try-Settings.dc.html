Yours only · saved as you change them · the same on every device

6 · Memory, on and off

One switch for every session

Off means two things at once: nothing new is remembered, and nothing already remembered is used. What is there stays until you forget it on the Memory tab. A single session can leave memory out from its Tools menu.

7 · The client-data check

Shown, not set

It is drawn among the settings so that nobody looks for a switch. There is none: Try TLM is not a place for a client's details, for anyone.

10 · A change, and going back

No hold anywhere on this page

A change takes effect at once, in the session you have open too, and can be undone for 10 seconds. Every choice here can be taken back, so nothing is held.
