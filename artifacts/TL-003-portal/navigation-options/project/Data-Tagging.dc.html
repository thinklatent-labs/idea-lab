When a person corrects a tag

The same three things every time
The item takes the person's tagFrom the next version on; versions already cut do not change. The tag is marked as set by a person, and a pipeline does not overwrite it.
The pipeline learns from itThe correction joins its next round of training. A new pipeline version is tried on last month's reviews before it replaces the old one.
The graph followsMixes that asked for the old tag are told at their next version, with the count that moved. A run already started keeps the items it was given.
