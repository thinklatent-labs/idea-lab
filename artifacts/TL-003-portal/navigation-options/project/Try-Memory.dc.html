2 · Edit one

"Edit", open

You can correct anything Try TLM learned. The line keeps where it came from and is marked as edited by you. The check for client data runs when you save.

Learned 3 Nov from the session "Turning notes into a checklist".

3 · Add something yourself

"Add something", open

A line you write is used like one Try TLM learned. Write how you work or how you like answers, not anything about a client or a case.

One thing a line. It is used from your next message.

4 · Forget one

With Undo

Forgetting one line happens at once and can be undone for 10 seconds. After that it is gone, and later answers no longer draw on it. Answers already written stay as they are.
