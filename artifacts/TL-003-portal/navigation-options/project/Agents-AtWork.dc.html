What an agent may do

The same for all five
Read what the person who asked can read, and nothing more Notice and propose. Every proposal names what it rests on and how sure it is Never decide: it does not change a model, a range, a member or a request Never send anything outside the portal. It prepares; a person sends
PlannedSmall steps agreed beforehand that an agent may take by itself and undo, reported afterwards. First for the SRE agent.

Stopping an agent

Only ThinkLatent can
ThinkLatent can pause an agent and must say why. A pause shows here and on every page where the agent appears, and nothing it had proposed is lost. A project owner who wants an agent stopped asks through Help; the answer comes from a person.
