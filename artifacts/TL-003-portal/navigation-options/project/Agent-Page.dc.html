How a task runs

Way A · typically 3 steps, never more than 5
1It findsEmbedding v2 searches the policy library the project gave it and takes the ten closest passages. 2It answersCore 4.2 writes the answer from those passages only, and names the source of each statement. 3It checksGuardrail v2 checks every statement against its source. 4If a statement has no source, it tries once moreIf there is still none, it says the policy does not answer the question, and who to ask.
In a project every step shows in Traces, under the one request the application made.
