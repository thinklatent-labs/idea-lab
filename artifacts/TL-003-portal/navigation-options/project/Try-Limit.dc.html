2 · What counts as a request

One ask of a model

A request is counted when a model starts to answer. It counts the same on every model, whether the answer is one line or a long piece of agent work with many steps.

3 · What does not count

Nothing a model did not answer

If no model answered, nothing is counted. Nor is anything Try TLM does around the chat, or anything you do that is not asking a model.

5 · An agent's task that reaches the limit halfway

Finished, never cut off

An answer that has begun is always finished: its steps and tool calls belong to one request. What cannot start at the limit is a new request, so a helper is not sent. The agent does that part itself, or says what is left.

6 · Schedules and the limit

A run is a request like any other

A scheduled run takes one request, and one for each helper it sends, from the day it runs. If the day is used up when a run comes due, the run is skipped and says so. It is not queued, so a missed run cannot use up tomorrow.

9 · Asking for more

The limit is the same for everyone

The limit is not raised for a person, a team or a deadline. More comes with a project: an endpoint of its own, where what counts is the room on its machines and not a number for the day.

10 · Where the limit lives

In the gateway, not in the chat

Every request to a model passes the gateway, and the gateway keeps the count. So a message, a second model, a helper and a scheduled run are counted in one place, across your devices and tabs. The chat shows the number and cannot change it.
