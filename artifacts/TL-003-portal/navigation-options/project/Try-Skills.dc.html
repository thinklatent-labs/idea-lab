2 · One skill, open

Its description, its instructions and its files

The description is what a model reads to decide whether the skill fits the task. The instructions and files are read only once it is picked up, so a skill takes almost no room in the context until it is used.

Write a fee comparison
Yours · version 3 · saved 4 Nov · on for Research helper and 1 session
Description
Use when asked to compare what two or more funds charge. Sets the charges out as a table, dearest first, with the cost over ten years and a short note.
InstructionsAbout 120 tokens when picked up
When asked to compare the fees of funds:
  1. Read each fund's yearly charge from the sheet or product sheet you are given. Use no other source.
  2. Work out the cost over ten years on 10,000 with ten-year-cost.py.
  3. Set the funds out as in fee-comparison-layout.md, dearest first.
  4. End with a note of five lines or fewer, in plain words. Say so if the figures are made up.
Files · 2

How it is picked up
"When it fits": the model picks it up from its description. "When you ask": you type / and its name.

4 · Upload one

"New skill", then "Upload one"

A skill written elsewhere can be brought in as one instructions file, or as a zipped folder that holds one. Every file in it is checked before anything is kept; if one file fails, nothing from the upload is kept.

5 · Switch it on

For a session, or for an agent

On for a session, the skill is there from the next message. On for an agent, it goes wherever the agent is used. A skill adds no access: it works with the tools the session or the agent already has.

10 · Remove a skill

Undo, or hold when something uses it

A skill nothing uses is removed at once, with Undo. If an agent uses it or it is shared, removing it changes things for them and cannot be taken back, so it is held.

Removed: "House style for notes"
Remove "Write a fee comparison"
Research helper uses it and it is shared with 2 people. The agent goes on without it; Lena W. and Dev R. lose it. Copies they made are theirs.
