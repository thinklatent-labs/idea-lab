5 · The summary, in the session

A marked message

The summary sits in the session where it was made, marked as a summary. Everything above it stays readable. To undo it, go back to before it: the session carries on from there as it was, and what followed the summary is kept as a branch.

A session can be summarised more than once. Each summary is its own marked message.

7 · A long file is searched, not sent whole

Two files, handled two ways

A short file is sent whole with every message. A long one is searched for each message, and only the passages that bear on it are sent, so a long document does not fill the context.
