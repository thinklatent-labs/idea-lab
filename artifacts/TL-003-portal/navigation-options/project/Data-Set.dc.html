A withdrawal to decide

Waits for Hana O., since 28 Oct

On 28 Oct, Call processing asked for 412 calls to be taken out of this set. Version 8 was withdrawn and version 9 was cut without them the same day, so nothing new will learn from those calls. One live model already has: Domain-Advice v2, and Advisor desktop's own version of it. The 412 calls are 0.02% of what it was trained on.
