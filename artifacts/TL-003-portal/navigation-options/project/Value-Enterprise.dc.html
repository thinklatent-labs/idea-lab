How the layers add up

Layers 1 to 3 are money. Today only layer 1 has a total, so it is the whole of "cost avoided" wherever that number appears.

Layer 4 is time. It is shown in hours beside the money and is not turned into money here.

Layer 5 is counted and never priced.

Nothing is counted twice: a use that started on an existing model is in layer 3, not layer 2.
