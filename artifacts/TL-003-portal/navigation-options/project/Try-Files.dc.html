4 · A file refused by the check

Not read, not kept

The check for client data runs on every file: when it is attached, saved, added to a folder, an agent or a skill, and when an agent makes one. A refused file is not read by a model and nothing of it is kept.

"holdings.xlsx" was not read and not kept
It looks like it holds client account numbers. It is not in your files, not in the session and was not shown to a model.
Why
"locked-report.pdf" could not be opened
A file that cannot be read cannot be checked, so it is refused too. Take the password off and add it again.

6 · Save, and download

Two ways to keep a file

Saving keeps a file in Try TLM until you remove it. Downloading takes a copy to your computer, and is recorded like everything that leaves Try TLM.

Save to your filesFrom this list, from a message, or from an artifact · the file no longer goes with its session DownloadThe file as it is · recorded with the time and its name, not its content
Saved: "sample-funds.csv" is now kept until you remove it

7 · Remove one

Undo, or hold when something uses it

A file nothing uses is removed at once, with Undo for 10 seconds. If a session, folder, agent or skill still uses it, removing it changes what they know and cannot be taken back, so it is held.

Removed: "old-fee-table.pdf"
Remove "fee-glossary.pdf"
The agent Fee explainer uses this file. Once it is removed, the agent no longer knows it, in every session from then on.
Hold for 2 seconds. Letting go cancels. From the keyboard, hold Space.
