The data format

One row a case · JSON Lines or CSV · the same format for every feature
FieldNeededWhat goes in it
idAlwaysYour own id for the case; it must not repeat.
inputAlwaysWhat the feature receives: here, the call transcript.
referenceBy typeThe right answer, or its key points. For exact match, closeness, and some judges.
reference_itemsBy typeThe right items as a list. For F1 score.
contextOptionalDocuments the feature was given, when it looks things up.
tagsOptionalYour own groups, to see scores by slice: long calls, a product.
