Schedules

An agent run at set times
Research helper · every Monday 08:00 ET'Summarise what changed in the sample fund sheets' · last run 2 NovPause
A run counts against your daily limit, lands in your inbox, and is a session like any other: yours, for 30 days. It runs with your access, and stops while you are away unless you say otherwise.

Subagents

An agent hands part of the work to a helper
Research helperAsked 2 helpers: read the three sheets · check the arithmetic2 of 2 done
Each helper has its own context and shows as a step you can open. Helpers use the same model, tools and limits as the agent that called them, and nothing more.

A code workspace

An agent can read, change and run files in a workspace. Only in ThinkLatent's sandbox inside the Enterprise, with no network; never on your own machine (D-322).

Images

Leaves the Enterprise
A made-up picture
"A simple diagram of fees taken from a fund each year, flat colours"Made by [an outside image model] · 9 seconds · counted in your limit
ThinkLatent has no image model, so pictures are made by one outside model that ThinkLatent allows (D-322). What you type for a picture goes to that model: the check for client data runs first, the session shows that it left, and every such request is listed for ThinkLatent.
Open: which outside model, and the Enterprise's Risk and IT security have not been asked. Until they are, this stays switched off in the build.
