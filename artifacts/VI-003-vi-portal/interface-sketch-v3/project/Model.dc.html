How to call it

Nucleus from Artifactory; the client follows the OpenAI shape. The use case and stage are required at creation; the task tag travels with each call; feedback is one line.

from nucleus import Client

client = Client(use_case="call-summary", stage="production")

r = client.chat.completions.create(
    model="vglm4-call-summary",
    messages=messages,
    metadata={"task": "summarise", "prompt_id": "summary-v3"},
)

client.feedback(r.id, score=1)
Proposed shape under the telemetry contract v0; today the model name names the endpoint and the tags are optional.
