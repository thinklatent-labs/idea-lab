## Discoverability (replaces chat naming)

Chat titles are no longer part of the lab: they needed manual renaming and did nothing a search could not. Discovery now runs on Claude's side.

1. **The register is the index.** Every session reads it first, so every idea, doc, link and next step is found from here, never from a chat list.
2. **Session tag in the first reply.** Each lab session opens with a line naming the register IDs and slugs it touches and the mode (for example: Lab session · TL-004 index · Critic). Past-chat search is a text match, so a search for TL-004 or index finds every session on it without any renaming.
3. **Sessions log below.** Every session adds one row: date, ideas, mode, outcome and docs touched. A returning session reads the log instead of hunting for chats.
4. **Aliases in every lab record.** Doc lab records carry the other names an idea goes by (the portal, the index), so a loose reference matches the right row.
5. **Docs carry the slug.** Doc titles keep the name-slug-type form, set by the thinking partner at creation; no manual step.
6. **Project search.** The nightly sync mirrors the register and Operating Model into project knowledge, so project search finds today's state from any session.

**Session scope.** One chat, one scope: a single idea, a Portfolio session, or Lab operations, declared in the first reply. Work for another scope is noted in one line and left for its own chat. Lab-operations chats never change an idea's stage, score or doc.
